# Build Chunk Template

Use this template for every implementation task.

## Goal

- What outcome will exist after this chunk?

## Blast Radius

- Which files, services, environments, and users can be affected?

## Rollback

- Exact steps to revert this chunk safely.

## Exit Criteria

- Objective checks that must pass before merging.

## Codex Task Prompt

- A precise prompt Codex can execute deterministically.

## Manual Command Alternative

- Equivalent manual commands for an operator to run.

## Expected Output / Verification

- Exact expected output signals and how to verify them.
